# Sistema eletrônico

A arquitetura eletrônica será integrada após a montagem mecânica de bancada. A caixa dorsal do antebraço é reservada para a eletrônica; o servo principal não é instalado nessa caixa.

## Componentes definidos

- microcontrolador compatível com leitura analógica e controle PWM;
- 1 servo DS3225-270, 25 kgf·cm, para flexão dos quatro dedos longos;
- 1 servo auxiliar de aproximadamente 15 kgf·cm para o polegar;
- 5 sensores de força FSR402;
- alimentação dedicada para os servos, com terra comum ao controle;
- conversão/regulação para a eletrônica de controle;
- proteção por fusível e chave de desligamento.

A seleção final de corrente, condutores, conectores e limites de software será confirmada no ensaio de bancada.
